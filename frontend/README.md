# Streamlit Frontend (PhishGuard)

## Purpose
- Provide a lightweight interface for manual phishing URL detection testing.
- Allow analysts to paste URLs and review model responses in real time.

## Future Improvements
- Add risk score bar and confidence indicators.
- Display prediction logs and history for auditing.
- Apply custom theming consistent with PhishGuard branding.

## Backend Integration (Planned)
- Connect to the FastAPI `/predict` endpoint for live inference.
- Present prediction labels, confidence scores, and explanations once available.
